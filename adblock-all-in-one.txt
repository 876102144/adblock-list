# ==== v3 关键修正（依据 2026-11-09 设备日志 12.99 万条 / 5600 域名）====
# 1) 移除 tnc* / frontier* / vcs / polaris5 / saveu5 拦截
#    实测 tnc 被拦 99%(556/562)、frontier 78%(260/335)，它们不是广告，
#    是字节的「流量调度 + 统一接入网关」。拦了 = 播放器拿不到 CDN 地址/鉴权
#    → 正片黑屏、一直转圈。这是"屏蔽视频本身"的主因。
# 2) 移除 ||ndcpp.com^
#    该域是腾讯视频 CDN（vc-gate / lf*-vccdn），整域拦 = 腾讯视频正片播不出。
# 3) 移除 p3/p6/p9-ad-sign.byteimg.com
#    只是广告图片"签名"服务，拦了会让播放器反复重试直到超时，整段卡死。
# 4) 移除 i-lq.snssdk.com / webcast5-open-hl.douyin.com
#    图片与直播主链，非广告投放域。
# 5) 新增 35 条 @@ 关键放行，防止上游订阅再次误伤这些链路。
#
# ⚠️ 关于"WiFi 已连接但无法上网"：日志已确认 DNS 链路(853/100.64.100.1/
#    fd00::1/dns.weixin.qq.com.cn) 全部未被规则拦截，问题出在拦截器本身
#    同时启用「VPN + Root 全局代理」两层。规则改不动它，需要：
#      · 关闭 Root 全局代理，只保留 VPN/DNS 过滤其中一层
#      · 不要开启「拦截 DoT / DoH 绕过」
#      · 断网时先临时关闭拦截器验证
#
# 维护原则：只拦「广告投放 / 埋点统计」域名；
#          绝不拦「调度(tnc) / 接入(frontier) / 配置(vcs) / 签名(-sign) / CDN」。
